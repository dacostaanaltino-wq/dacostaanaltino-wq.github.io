# Linux System Hardening Lab — Fedora

- **Statut :** Personal Lab — In Progress.
- **Contexte et objectif :** étudier les utilisateurs et permissions, SSH, le pare-feu, les mises à jour et les contrôles de sécurité de base sur une VM Fedora.
- **Ma contribution :** le dépôt local contient un ensemble de scripts Bash, audits, documentation de menaces, vérifications et procédure de rollback; exécution personnelle à confirmer.
- **Technologies et outils :** Fedora 44, Bash, OpenSSH, firewalld, SELinux, auditd, fail2ban et shellcheck indiqués dans le README du lab.
- **Fonctionnalités :** scripts d'audit initial, durcissement SSH, comptes, pare-feu, services/noyau, audit et vérification PASS/FAIL.
- **Architecture :** VM Fedora de laboratoire avec snapshot recommandé; scripts de changements prévoient dry-run et sauvegardes selon la documentation du dépôt.
- **Captures et résultats :** les dossiers d'évidence existent mais ne contiennent pas de résultats personnels constatés.
- **Apprentissages :** à compléter après exécution et rédaction personnelle.
- **Limites et suites :** exécuter dans une VM, vérifier les sorties, ajouter preuves anonymisées et décrire les changements réellement observés.

Aucune expérience professionnelle SOC, réponse à incident ou administration de production n'est revendiquée.
